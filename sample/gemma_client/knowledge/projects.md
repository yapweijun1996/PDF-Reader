# Projects

## QR Code Generator
The public website includes a QR Code Generator tool at `yapweijun1996.com/tools/QR-Code-Generator/index.php`. The tool supports QR styling controls such as shape, color, border style, center style, logo upload, and export to PNG or SVG.

## PayNow QR Generator
The public GitHub repository `yapweijun1996/PayNow-QR-Generator` describes a web application that generates PayNow QR codes from payment details such as UEN, amount, expiry date, reference number, and company name. The README also mentions optional logo support and a GitHub Pages demo.

## ScreenClip Pro
The public repository `yapweijun1996/Screen-Recorder-React-JS-Frontend` describes ScreenClip Pro as a browser-side screen recorder and editor. It can capture a display, trim the result, and export MP4 entirely on the client using React, Vite, and FFmpeg.wasm.

## WiFi QR Code Generator
The public repository `yapweijun1996/WiFi-QR-Code-Generator` describes a web application that generates WiFi QR codes from SSID, password, and encryption type, allowing mobile devices to join a network by scanning the generated code.

## Dropbox Link Converter
The public repository `yapweijun1996/Dropbox-Link-Converter` describes a small web app that converts standard Dropbox sharing links into direct download links and provides one-click clipboard copy support.

## Public Project Themes
Across the website and public repositories, the recurring project themes are browser-native utilities, QR and sharing tools, client-side media processing, and lightweight web applications built with HTML, CSS, JavaScript, and related frontend tooling.
